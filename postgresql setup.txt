## 2. Make PostgreSQL work from any directory

Currently, you need to specify the full path to `psql.exe`. To avoid that, add PostgreSQL to your Windows PATH.

**Follow these steps:**

1. Press `Win + R`.
2. Enter `sysdm.cpl` and press Enter.
3. Open the **Advanced** tab.
4. Click **Environment Variables**.
5. Under User variables, select `Path`.
6. Click **Edit**.
7. Click **New**.
8. Add this directory:

   `C:\Program Files\PostgreSQL\18\bin`

9. Click OK on all windows.
10. Close CMD and open a new CMD window.

Test it:

```cmd
psql --version
```

You should now see `psql (PostgreSQL) 18.6` without specifying the full path.

## 3. Create your first database

Open CMD and connect:

```cmd
psql -U postgres -h localhost -p 5432
```

Enter your PostgreSQL password.

Create a database:

```sql
CREATE DATABASE student_db;
```

Connect to it:

```sql
\c student_db
```

Create a table:

```sql
CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    department VARCHAR(100),
    age INT
);
```

Insert sample data:

```sql
INSERT INTO students (name, department, age)
VALUES ('Afzal', 'MCA', 21);
```

Display the records:

```sql
SELECT * FROM students;
```

List all databases:

```sql
\l
```

Exit PostgreSQL:

```sql
\q
```

**Note:** Your PostgreSQL installation is already successful. You do not need to reinstall it.

If you are installing PostgreSQL for your **Java JDBC practicals**, the next step is to configure the PostgreSQL JDBC driver in your Java project.
